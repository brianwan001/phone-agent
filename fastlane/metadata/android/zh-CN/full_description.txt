Phone Agent 是一个替你操作真实手机的 AI 智能体。用一句自然语言（打字或语音）下达任务，它用视觉大模型看屏幕、用规划大模型想步骤，通过无障碍服务驱动界面：打开应用、搜索、点按、输入、滑动——甚至替你发一条评论。

<b>工作方式</b>
• 视觉模型理解截图，规划模型决定下一步动作
• 通过无障碍服务执行点按、长按、输入和手势
• 三级点击链，每步执行后视觉验证
• 工具箱：拉起应用、等待屏幕文字、放大检查小控件、按图标找应用

<b>记忆与复盘</b>
• 语义记忆跨会话记住事实
• 经验库记录成功路径并自动复用
• 运行记录带逐帧日志，可回看复盘

<b>语音下单</b>
• 说一句话即可执行：本机录音(16kHz 单声道 PCM)→转写→执行
• 全程免手操作

<b>面向激进 ROM 的可靠性</b>
• 前台服务 + Wake Lock，电池优化白名单引导
• 专门对抗 MIUI / HyperOS 的进程冻结

<b>自带模型</b>
• 任意 OpenAI 兼容端点（默认预设：智谱 BigModel）
• API key 由你自己填写——不内置任何凭证，无需注册任何账号

开源（MIT）。无广告、无跟踪、无统计、无专有 SDK。需要 Android 11+。可选 Shizuku 用于提权操作。
