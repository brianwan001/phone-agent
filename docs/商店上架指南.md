## 【详细描述】(复制粘贴)

Phone Agent 让 AI 替你操作真实的安卓手机:它用"眼睛"看屏幕、用"手"点界面。你只需要给一句目标,例如"打开小红书,搜索深圳创业沙龙,打开第一篇笔记告诉我标题和作者",它就会自动规划、逐步点击、实时验证,直到完成。

✨ 核心能力
• 零电脑零 root:一个 App 搞定,无障碍服务原生模拟点击/滑动/中文输入
• 双模型大脑:GLM-4.5V 负责看屏幕定位,GLM-5.3-Flash 负责规划推理(支持任意 OpenAI 兼容接口)
• 越用越聪明:每次任务结束自动复盘,沉淀"经验教训",同类任务越跑越快
• 实时视角:执行中可看到 Agent 眼中的屏幕画面
• 工具箱:直启 App、等待页面文字、放大细看、剪贴板输入
• 稳定可靠:卡死自动熔断、更强模型自动兜底、暂停可断点续跑
• 全程可回放:每步截图+动作留痕,支持导出

🎯 使用场景
• 信息搜集:在社交平台搜索、浏览、汇总
• 建联触达:找到目标用户,帮你写好招呼语(草稿模式,发送由你确认)
• 重复操作:设置、闹钟、批量查看
• 无障碍辅助

🚀 快速开始
1. 安装后进入设置,填入你的 AI 接口地址和密钥(OpenAI 兼容格式,如智谱/硅基流动等)
2. 开启无障碍服务(一键引导)
3. 输入目标,点击启动,看它干活

⚠️ 使用须知
• 只自动化你拥有或被授权的设备与账号,遵守相关平台条款
• 需要 Android 11 及以上
• 需自行准备 AI 模型接口(本应用不提供模型服务,不收取模型费用)

## 【权限说明】(商店/用户问起时用)

• 无障碍服务:核心功能,用于截取屏幕与模拟点击;可随时在系统设置中关闭
• 麦克风:仅在使用语音输入任务时录音,音频仅上传至你自己配置的识别服务
• 通知:显示任务执行状态
• 网络:连接你自己配置的 AI 接口
• 不收集、不上传任何用户数据;截图、任务记录、经验库全部仅存本机

## 【隐私政策】(发布到公开网页后填链接)

# Phone Agent 隐私政策

Phone Agent 不含任何账号系统,不收集、不传输、不出售任何个人数据。

1. 屏幕截图与任务记录:仅存储在设备本地(files/runs/),用户可随时删除或导出。
2. 麦克风:仅当用户主动使用语音输入时录音;录音经转写后立即删除本地副本,音频数据仅传输至用户自行配置的语音识别服务。
3. 屏幕内容:执行任务期间的截图仅发送至用户自行配置的 AI 模型接口,用于完成用户下达的任务。
4. 经验库:任务结束后的经验总结仅存储在设备本地。
5. 第三方服务:应用不内置任何第三方统计、广告或追踪 SDK。

联系方式:随应用分发渠道提供。
