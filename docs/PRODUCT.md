# Phone Agent 产品介绍

**一句话**:装在安卓手机里的 AI 操作员——眼睛看屏幕、手上点手机、越用越懂你的手机。零硬件、零电脑、零 root。

## 它能做什么

给一句自然语言目标,它自己在真机上完成:

- "在小红书搜'深圳创业沙龙',打开第一篇,告诉我标题和作者" → 32 秒,7 步,done
- "打开计算器算 12×34" → 61 秒,自动纠错,报出 408
- "找深圳组局的人,进私信打好招呼草稿(不发)" → 自动选关键词、进作者主页、中文输入

适合:获客建联、私域触达草稿、重复性 App 操作、无障碍代操作、批量截图取证。

## 核心能力

| 能力 | 说明 |
|---|---|
| **零电脑零 adb** | 不像 ADB 方案要拖着一台电脑;无障碍服务原生模拟键鼠(比蓝牙键鼠还快,免配对) |
| **双脑分工** | 视觉定位 GLM-4.5V + 规划推理 GLM-5.3-Flash;任意 OpenAI 兼容端点可换(Qwen-VL/UI-TARS/Gemini…) |
| **有记忆,会积累经验** | 每次成功任务的路径自动蒸馏成"经验";下次同类任务直接带上历史路径,越跑越快越稳 |
| **工程级防呆** | 占位词污染拦截、输入落地校验(自定义输入框自动切剪贴板粘贴)、死循环熔断(坐标抖动也识别)、卡死自动转断点 |
| **国产机免疫** | 静音保活过 MIUI/HyperOS 冻结;前台通知随时 Stop,断点可 Resume |
| **全程可回放** | 每步截图+动作+变化标记;Runs 页逐步回放,一键导出 zip 供复盘/二次训练 |

## 优劣势(诚实版)

### 优势

1. **部署成本最低**:一个 APK,不用电脑/adb/root/开发者选项——ADB 方案的全套门槛(USB 调试、授权、掉线)全部消失
2. **不开放 adb = 更安全**:adb 是手机的全权限后门,我们只申请一个无障碍服务,权限面小一个数量级;API key 加密存本机
3. **稳**:无线 adb 会抖、会被 MIUI 杀;我们无连线概念,配合保活长时间任务不断
4. **越用越聪明**:经验库是本机私有的(数据不出手机),同类任务直接复用历史路径
5. **可审计**:每一步都有截图证据链

### 劣势(现状)

1. 按键注入弱:无系统级回车注入 API(用换行模拟);蓝牙 HID 键盘路线图可补
2. FLAG_SECURE 界面(银行/无痕页)截屏全黑,看不见就操作不了
3. 部分金融 App 检测无障碍服务会拒跑
4. 单机单任务;设备农场场景(一控多)不适合,那该用 ADB
5. 模型上限:GLM-4.5V 级视觉对复杂 UI 仍会犯错(有熔断和重试兜底,不保证一次成)
6. 相比 OpenClaw 这类"通用 agent 网关":我们不做多渠道聊天接入/插件生态,只专精手机 GUI 执行——OpenClaw 需要一个"能动手"的执行器,本产品正好是那个执行器,互补而非竞争

## 技术架构(30 秒版)

```
你的目标 ──▶ GLM-5.3-Flash 规划 ──▶ GLM-4.5V 看截图+控件树 定位坐标
                    ▲                        │
              经验库注入(历史成功路径)         ▼
                    │              无障碍服务注入 点击/滑动/输入
                    └── 截图对比"变没变"反馈 ◀── 屏幕稳定检测
循环直到 done/fail;每步落盘可回放
```

## 演示脚本

**30 秒版**:计算器算 12×34(自我纠错后报 408)
**90 秒版**:小红书搜"深圳创业沙龙"→读笔记→(进阶)给作者私信打好草稿不发送
**跑法**:App 输目标点 Start,或 `adb shell am start -n tech.handsy.phoneagent/.MainActivity -a tech.handsy.phoneagent.AUTO_RUN --es goal '...'`
